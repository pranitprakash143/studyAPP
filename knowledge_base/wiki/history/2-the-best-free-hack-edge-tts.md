## Summary
Edge-TTS provides free premium, human-like voices by leveraging Microsoft Edge's hidden "Read Aloud" API. This API utilizes Azure's neural voices in the background, offering an alternative to paying for API keys or setting up heavy local models.

## Key Facts
- Edge-TTS offers premium, human-like voices for free.
- It utilizes Microsoft Edge's hidden "Read Aloud" API.
- The "Read Aloud" API uses Azure's neural voices in the background.
- Edge-TTS provides an alternative to paying for API keys or setting up heavy local models.
- For Python, the `edge-tts` library (`pip install edge-tts`) is available.
- The Python `edge-tts` library gives access to over 100 high-quality Microsoft voices.
- For JavaScript, community wrappers like `node-edge-tts` are available.
- `node-edge-tts` can be found on npm for Node.js environments.
