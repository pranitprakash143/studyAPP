## [`start.sh`](file:///Users/pranitprakash/Desktop/AI/APPS/aiDratAssistant/StudyApp/start.sh) — What It Does

```
ChromaDB → FastAPI Backend → Next.js
```

The script runs this sequence with health polling at each step:

| Step | What Happens |
|---|---|
| **1. Prerequisites** | Checks `docker`, `docker-compose`, `node`, `npm` are installed and Docker daemon is running |
| **2. .env validation** | Copies `.env.example` → `.env` if missing; warns if `GEMINI_API_KEY` is unset |
| **3. npm install** | Skips if `node_modules` already exists |
| **4. Docker build + launch** | Runs `docker-compose up chromadb backend --build --detach` with a spinner |
| **5. ChromaDB health poll** | Polls `/api/v2/heartbeat` every 2s, times out after 60s |
| **6. FastAPI health poll** | Polls `/health` every 2s, shows AI provider + ChromaDB status |
| **7. Next.js launch** | Starts `npm run dev` in background, polls port 3000 |
| **8. Live dashboard** | Prints all URLs, streams Next.js logs to terminal |
| **Ctrl+C** | Kills Next.js + stops Docker containers cleanly |

---

## Commands

```bash
# Start everything
./start.sh

# Or via npm
npm run dev:start

# Stop everything
./start.sh --stop
npm run dev:stop

# Nuclear reset (wipes ChromaDB volume)
./start.sh --reset
npm run dev:reset
```
